
# MathFun – Aplikasi Pembelajaran Operasi Bilangan Bulat

## Deskripsi
MathFun merupakan aplikasi pembelajaran matematika berbasis website yang dirancang untuk membantu siswa SMP memahami materi operasi bilangan bulat dengan cara yang menarik, interaktif, dan menyenangkan.

## Fitur Aplikasi
1. Beranda
2. Pretest
3. Materi Pembelajaran
4. Kalkulator Bilangan Bulat
5. Garis Bilangan
6. Latihan Soal
7. Posttest
8. Evaluasi
9. Backsound Musik

## Teknologi yang Digunakan
- React.js
- Vite
- JavaScript
- CSS
- HTML

## Cara Menjalankan Aplikasi

1. Clone repository:
```bash
git clone https://github.com/nadinenuraini6/aplikasi-pembelajaran-operasi-bilangan-bulat-2225250004.git
```

2. Masuk ke folder project:
```bash
cd aplikasi-pembelajaran-operasi-bilangan-bulat-2225250004
```

3. Install dependencies:
```bash
npm install
```

4. Jalankan aplikasi:
```bash
npm run dev
```

5. Build aplikasi:
```bash
npm run build
```

## Tujuan Pengembangan
Aplikasi MathFun dikembangkan sebagai media pembelajaran matematika interaktif untuk meningkatkan pemahaman dan minat belajar siswa SMP, khususnya pada materi operasi bilangan bulat.
